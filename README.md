# Иконостас

Библиотека SVG-иконок

## Возможности

- поиск по названию, имени файла;
- копирование SVG в буфер обмена с сохранением названия;
- скачивание исходного SVG-файла;

## Как добавить иконку

1. Положите SVG в `public/icons/<icon-name>.svg`. Имя файла — в kebab-case: строчные латинские буквы, цифры и дефисы.
2. Добавьте запись в `public/icons.json`:

```json
{
  "nodeId": "local:my-icon",
  "name": "24_icon-fill/my-icon",
  "file": "my-icon.svg"
}
```

`nodeId` — ID узла в Figma или `local:<имя>` для иконок, добавленных вручную. `name` становится названием иконки и `id` скопированного SVG: по нему Figma называет слой при вставке. Поля `x`/`y` у старых записей — координаты из Figma, приложение их не использует.

3. При необходимости добавьте поисковые теги в `public/icon-tags.json`:

```json
{
  "local:my-icon": ["custom", "example"]
}
```

4. Проверьте манифест:

   ```bash
   npm run check
   ```

   Скрипт сверяет `icons.json` с файлами в `public/icons/`: находит пропущенные записи и файлы, дубли, невалидные имена и одинаковые SVG. Та же проверка запускается в CI.

## Запуск проекта

Понадобятся Node.js 20.19+ (или 22.12+) и npm.

1. Откройте терминал в папке проекта.
2. Установите зависимости:

   ```bash
   npm ci
   ```

3. Запустите сервер для разработки:

   ```bash
   npm run dev
   ```

4. Откройте [http://localhost:5173](http://localhost:5173) в браузере.

Сервер слушает только `localhost`. Чтобы открыть сайт с телефона в той же сети, запустите `npm run dev:lan`. Учтите, что копирование в буфер обмена браузеры разрешают только по `https` или на `localhost`: по `http://192.168.…` сработает лишь запасной способ копирования, и то не во всех браузерах.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` создаёт готовые файлы в папке `dist`, а `npm run preview` запускает их локальный просмотр. Пути в сборке относительные, поэтому `dist` можно раздавать и из подкаталога (например, GitHub Pages).
