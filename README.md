# Иконостас

Библиотека SVG-иконок

## Возможности

- поиск по названию, имени файла;
- копирование SVG в буфер обмена;
- скачивание исходного SVG-файла;

## Как добавить иконку

1. Положите SVG в `public/icons/<file-name>.svg`.
2. Добавьте запись в `public/icons.json`:

```json
{
  "nodeId": "local:1",
  "name": "24_icon-fill/my-icon",
  "x": 0,
  "y": 0,
  "file": "my-icon.svg"
}
```

3. При необходимости добавьте поисковые теги в `public/icon-tags.json`:

```json
{
  "local:1": ["custom", "example"]
}
```

Такой формат оставляет место для будущего версионирования: новые версии можно добавлять отдельными файлами и записями, не ломая текущие ссылки.

## Команды

- `npm run dev` — локальная разработка;
- `npm run build` — production-сборка;
- `npm run preview` — просмотр production-сборки.
