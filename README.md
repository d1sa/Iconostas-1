# Иконостас

Библиотека SVG-иконок

## Возможности

- поиск по названию, имени файла;
- копирование SVG в буфер обмена;
- скачивание исходного SVG-файла;

## Как добавить иконку

1. Положите SVG в `public/icons/<file-name>.svg`.
2. Добавьте запись в `public/icons.json`:

```json
{
  "nodeId": "local:1",
  "name": "24_icon-fill/my-icon",
  "x": 0,
  "y": 0,
  "file": "my-icon.svg"
}
```

3. При необходимости добавьте поисковые теги в `public/icon-tags.json`:

```json
{
  "local:1": ["custom", "example"]
}
```

Такой формат оставляет место для будущего версионирования: новые версии можно добавлять отдельными файлами и записями, не ломая текущие ссылки.

## Запуск проекта

Понадобятся Node.js 20.19+ (или 22.12+) и npm.

1. Откройте терминал в папке проекта.
2. Установите зависимости:

   ```bash
   npm ci
   ```

3. Запустите сервер для разработки:

   ```bash
   npm run dev
   ```

4. Откройте [http://localhost:5173](http://localhost:5173) в браузере.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` создаёт готовые файлы в папке `dist`, а `npm run preview` запускает их локальный просмотр.
